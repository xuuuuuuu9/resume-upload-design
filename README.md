# Resume upload page

Front-end implementation of the resume upload screen in `前端工程师（实习）.fig`.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To verify the production build, run `npm run build`.

## Features

- Responsive desktop and mobile layout based on the Figma screen
- Click, keyboard, and drag-and-drop file selection
- Selected filename display and button interaction states

The supplied design does not include an upload API, so the selected file stays in the browser. The illustration is extracted from the supplied design file.
